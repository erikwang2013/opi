01 / 认识小欧

一枚键帽，
为什么值得被认真对待？

小欧是 opi 的项目宠物，也是一枚键帽精灵。它长得就是键盘上的一颗键 —— 因为输入法本该如此，不必是别的东西。

身体是键帽，嘴是字母 O（Open），头顶是拼音声调 ˉ，侧壁刻着 opi，底部涟漪只在本机扩散。
这些不是装饰，是项目对「输入」这件事的态度。

始于不满，成于热爱。—— opi 项目缘起

02 / 十二种形态

十二种小欧，
十二种心情。

它不只住在设置页。候选栏、空态、启动图标、状态栏 —— 小欧会在你打字的每个小瞬间出现。点任意一张，看看它的心情。

十二种形态均为 opi 自有资产，不是内置 emoji。输入法里以动画 GIF / PNG 贴纸插入，标签带「小欧·」前缀，和 emoji 不重名。

03 / 能力

不是功能堆砌，
是把每一件小事做对。

没有弹窗、没有账号、没有「猜你喜欢」。只有一条清晰的输入链路，和足够克制的工具。

01

一份引擎，六端原生

Rust 核心 + 平台原生外壳：Android IME、fcitx5、Windows TSF、macOS / iOS 键盘扩展、鸿蒙 N-API。同一套词库与键码；Android（模拟器）与 Linux（容器 / 本机）已验证，其余四端待真机验收。

Rust · C ABI · 六端代码
02

离线优先，隐私可核对

输入、候选、用户词都在本机完成。没有登录、没有云端同步、没有遥测；MIT 许可，代码可自己读。

零网络请求
03

中英文输入功能

拼音 / 简繁 / 双拼 / 五笔 / 笔画，26 / 9 / 14 键布局；9 键左列读音、候选平铺、中英与简繁都在当前输入法内切换；英文普通 / 专业模式、单词联想；模糊音、简拼、逐字确认与本地学习。

中 · 英 · 简繁 · 9/14/26 键

简体主库与繁体库分轨，康熙字典、现代繁体词与常用语持续并入；每条词库变更都有门禁和回归测试守着。代码 MIT，词库数据按 GPL-3.0 分发。

04 / 功能迭代

从一枚键帽，
走到六个平台。

不是一条直线：引擎、词库、平台外壳和表情系统互相拉扯着长大。这里是几个值得记住的节点。

  1. 2026.08

    引擎起步

    Rust 核心、拼音解析与词库管线成形；Android 原生 IME 跑通第一条输入链路。

  2. 2026.09

    桌面落地

    fcitx5 插件、Compose 候选窗与设置页、Windows TSF 骨架；Linux 成为第一个真实验证的桌面端。

  3. 2026.10.17–18

    小欧诞生

    十二种形态、OpenMoji、颜文字、自有贴纸与英文普通 / 专业模式；「小欧」成为输入法的名字。

  4. 2026.10.19–20

    多端交付

    iOS 宿主 App 与 unsigned IPA、鸿蒙 HAP 脚手架、Windows 注册链路修复、状态栏统一缩放；官网与 v1.16.0。

  5. 2026.10.21

    候选与安装收口

    iOS 9 键读数列 / 平铺候选 / 输入法内切换；Windows TSF 升级替换与无重启卸载；iOS / macOS 改为单一自包含包，v1.20.2。

装完必做：Linux 把 OPI 加进 fcitx5 输入法组；Windows 在「中文(简体)」键盘列表添加「小欧输入法」并注销 / 重启一次；iOS 在设置 → 通用 → 键盘中添加并允许；macOS 在输入源中添加。

下载目录的版本与文件名和 dist/ 保持一致；页面版本 v1.20.2。
