01 / 认识小欧

一枚键帽，为什么值得被认真对待？

小欧是 opi 的项目宠物，也是一枚键帽精灵。它长得就是键盘上的一颗键 —— 因为输入法本该如此，不必是别的东西。

身体是键帽，嘴是字母 O（Open），头顶是拼音声调 ˉ，侧壁刻着 opi，底部涟漪只在本机扩散。这些不是装饰，是项目对「输入」这件事的态度。

  • Open：引擎开源，词库开放，透明可审计。
  • People：为人人设计，不拿输入做别的事。
  • Input：回归输入本质，只把字打对。
  • 云同步、账号、广告与遥测，都不做。

02 / 能力

不是功能堆砌，是把每一件小事做对。

没有弹窗、没有账号、没有「猜你喜欢」。只有一条清晰的输入链路，和足够克制的工具；云同步已裁决不做，未做的边界以 README 为准。

一份引擎，六端原生

Rust 核心 + 平台原生外壳：Android IME、fcitx5、Windows TSF、macOS / iOS 键盘扩展、鸿蒙 N-API。同一套词库与键码，UI 各写各的。

RustC ABIAndroidWindowsLinuxmacOSiOS鸿蒙

Android（模拟器）· Linux（容器 / 本机）。其余四端已有可构建产物，尚未真机验收。

离线优先，隐私可核对

输入、候选、用户词都在本机完成。没有登录、云端同步与遥测；联网仅用于拉取 version.json，不携带输入数据。

03 / 功能迭代

从一枚键帽，走到六个平台。

不是一条直线：引擎、词库、平台外壳和表情系统互相拉扯着长大。这里是几个值得记住的节点。

  1. 2026.08起点

    引擎起步

    Rust 核心、拼音解析与词库管线成形；Android 原生 IME 跑通第一条输入链路。

  2. 2026.09桌面

    桌面落地

    fcitx5 插件、Compose 候选窗与设置页、Windows TSF 骨架；Linux 成为第一个真实验证的桌面端。

  3. 2026.10.17–18小欧

    小欧诞生

    十二种形态、OpenMoji、颜文字、自有贴纸与英文普通 / 专业模式；「小欧」成为输入法的名字。

  4. 2026.10.19–20多端

    多端交付

    iOS 宿主 App 与 unsigned IPA、鸿蒙 HAP、Windows 注册链路修复、状态栏统一缩放；官网与 v1.16.0。

  5. 2026.10.21收口

    候选与安装收口

    iOS 9 键读数列 / 平铺候选 / 输入法内切换；Windows TSF 升级替换与无重启卸载；Apple 改为单一自包含包。

  6. 2026.10.22v1.23.1

    热升级与键盘内设置

    Windows 交互式升级重启原用户桌面、功能键与空缓冲特殊键放行、切换输入法释放状态栏；Android / 鸿蒙工具条齿轮改为键盘内设置页。

    26 键单键有限窗口在全量池上按档位选择、只物化首位段（桌面 release 单键 3.5–6ms）；9 键单键不再做无意义回退扫描；有限窗口与全量列表逐条同前缀，修复「看到百度、上屏不饿」。

04 / 十二种形态

十二种小欧，十二种心情。

它不只住在设置页。候选栏、空态、启动图标、状态栏 —— 小欧会在你打字的每个小瞬间出现。点任意一张，看看它的心情。

十二种形态均为 opi 自有资产，不是内置 emoji。输入法里以动画 GIF / PNG 贴纸插入，标签带「小欧·」前缀，和 emoji 不重名。
