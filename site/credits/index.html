开源致谢

小欧输入法（opi）站在许多开源项目与社区的肩膀上。下面按类别列出实际使用的上游；词库与视觉资产的逐条许可见 词库许可 与 视觉资产许可。

项目与许可
  • 小欧输入法（opi）源代码以 MIT 许可开源；词库数据与视觉资产按各自许可分发。
  • 简体主词库因并入 GPL-3.0 数据而整体按 GPL-3.0 分发；完整许可文本随仓库与安装包提供。
Rust 与开源 crate
  • Rust 语言、标准库与 Cargo 工具链（Rust 项目及其贡献者）
  • serde / serde_json（数据序列化）
  • memmap2（内存映射词库）
  • jni（Android JNI 绑定）
  • snow / x25519-dalek（Noise 协议与密钥交换）
  • postcard / sha2 / hex / getrandom / socket2（跨设备传输）
  • thiserror（错误处理）
  • windows-rs（Windows TSF / IMM32 绑定）
  • sherpa-rs（sherpa-onnx 的 Rust 绑定）
  • proptest / hound（测试与音频读取，开发期）
  • 以及 Cargo.lock 中的全部传递依赖及其贡献者
词库与数据来源
  • rime-ice（雾凇拼音）、rime-essay、rime-luna-pinyin、rime-pinyin-simp、rime-terra-pinyin、rime-stroke、rime-wubi、rime-cangjie
  • chinese-xinhua（成语与歇后语）
  • THUOCL（清华大学开放中文词库）
  • 康熙字典数据（shunshi-kangxi-core，Shunshi.AI）
  • OpenCC（简繁转换）、Unicode Unihan 与 Unicode 字符数据库
  • Google Books Ngram Frequency（英文联想词源）
  • 百家姓（公有领域）与项目人工整理表
  • 及相关贡献者；逐条来源与许可见 词库许可
