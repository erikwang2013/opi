Open-source credits

opi stands on many open-source projects and communities. These are the upstream projects actually used; per-source licensing is in dictionary licenses and visual-asset licenses.

Project and licensing
  • opi source code is MIT-licensed; dictionary data and visual assets are distributed under their own licenses.
  • The main Simplified dictionary is distributed as GPL-3.0 because it includes GPL-3.0 data; full license texts ship with the repository and installers.
Rust and open-source crates
  • Rust language, standard library and Cargo toolchain (the Rust project and contributors)
  • serde / serde_json (data serialization)
  • memmap2 (memory-mapped dictionaries)
  • jni (Android JNI bindings)
  • snow / x25519-dalek (Noise protocol and key exchange)
  • postcard / sha2 / hex / getrandom / socket2 (LAN transfer)
  • thiserror (error handling)
  • windows-rs (Windows TSF / IMM32 bindings)
  • sherpa-rs (Rust bindings for sherpa-onnx)
  • proptest / hound (testing and audio reading, development only)
  • All transitive dependencies in Cargo.lock and their contributors
Dictionaries and data
  • rime-ice, rime-essay, rime-luna-pinyin, rime-pinyin-simp, rime-terra-pinyin, rime-stroke, rime-wubi, rime-cangjie
  • chinese-xinhua (idioms and xiehouyu)
  • THUOCL (Tsinghua Open Chinese Lexicon)
  • Kangxi dictionary data (shunshi-kangxi-core, Shunshi.AI)
  • OpenCC (Simplified/Traditional conversion), Unicode Unihan and the Unicode Character Database
  • Google Books Ngram Frequency (English association source)
  • Baijiaxing (public domain) and project-maintained tables
  • And related contributors; per-source details and licenses are in dictionary licenses
Platforms and frameworks
  • Android: Kotlin, Jetpack Compose, AndroidX
  • Apple: Swift, UIKit, InputMethodKit, AppKit
  • HarmonyOS: ArkTS, ArkUI, HarmonyOS SDK
  • Linux: fcitx5
  • Windows: Text Services Framework (TSF), IMM32, Win32
  • Desktop: Compose for Desktop, Skiko, JNA

Speech recognition
  • sherpa-onnx (k2-fsa project and contributors)
  • SenseVoice (FunAudioLLM / Alibaba Tongyi Lab and contributors)
  • Whisper (OpenAI and contributors)

Cross-device transfer

Others
