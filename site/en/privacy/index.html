Privacy Policy

opi (Open People Input) · consistent across all six clients

Issued by: the opi project (“小欧输入法”)

Operator and contact: erik (艾瑞可erik), individual developer

Contact email: erik@erik.xyz

Effective date: October 28, 2026

Applies to: the Android, iOS, HarmonyOS, Windows, Linux and macOS clients, and this website (opi.erik.xyz)

In one sentence: opi collects, uploads and shares no personal information. There are no accounts, so there is no account-deletion process. Normal typing is fully offline; the client only goes online when you check/download an update or enable cross-device clipboard. Clipboard data never goes through a cloud.

1. What we collect

We collect no personal information, including but not limited to: your input and candidates, clipboard contents, contacts, location, photos, device identifiers, usage statistics or crash logs. There are no accounts, registration or sign-in, and no advertising or profiling.

2. Data kept only on your device

Settings, skins, switches, user words and learning data stay on your own device (in the app data or configuration directory of each client). They do not leave the device. Because there are no accounts, there is no account to delete; clearing local data removes everything:

  • Android / HarmonyOS: uninstall the app or clear its data in system settings.
  • iOS: deleting the app deletes the keyboard extension container; typing works without granting “Allow Full Access”.
  • Windows / Linux / macOS: delete the local configuration and user-word files, or uninstall the app.

3. Network access (only when you initiate it)

Normal typing is fully offline. Network access happens only in these cases:

  • Update checks: some clients offer “Check for updates”, which sends one ordinary HTTPS request to https://opi.erik.xyz/version.json to read the latest version number. It does not carry input, user words, clipboard contents or device identifiers, and is not used for statistics or profiling.
  • In-app updates: when you press Download, the client fetches the installer/hot-update package and verifies its size and SHA-256; no input or user data is sent.
  • Cross-device clipboard (optional, off by default): only after you enable it and pair devices does the client open an encrypted connection (Noise + ChaCha20-Poly1305) to paired devices on the same LAN. Only plain text (≤256 KiB) is synced; discovery packets contain no clipboard contents; there is no cloud, no account and no history, and you can stop/revoke at any time. Your OS’s own cloud clipboard may sync independently; turn it off in system settings if you do not want that.

4. System permissions

  • Android: INTERNET (updates/clipboard), REQUEST_INSTALL_PACKAGES (handing a downloaded package to the system installer), optional LAN multicast and foreground-service/notification permissions (cross-device clipboard).
  • iOS: optional “Allow Full Access” for writing the app’s own sticker images; optional local-network permission for cross-device clipboard. Keyboard extensions cannot use the microphone; use system dictation for voice.
  • HarmonyOS: network permission (updates/clipboard), optional pasteboard permission only when the clipboard feature is enabled.
  • Windows / Linux / macOS: the firewall may ask on first clipboard listen.

5. Third parties and sharing

We do not sell, lend or share personal information, and we integrate no third-party advertising, analytics or tracking SDKs. This website is static: it sets no analytics cookies and loads no third-party analytics scripts.

6. Children’s privacy

Because we collect no information at all, we do not (and cannot) collect personal information from children.

7. Data security

Input and user words never leave your device, so there is no server-side input data to breach. Update checks only read a public version number over HTTPS.

8. Your rights

Since we hold no personal information, there is no server-side data to access, correct, export or delete. Local data is always under your control: clear the app’s data or uninstall it. If you have questions, email us.

9. Changes to this policy

This policy may be updated as the product changes. The new version will be published on this page with a new effective date. Because there are no accounts, we cannot notify users individually; this page is the authoritative version.

10. Contact us

For any privacy question, email erik@erik.xyz. This is an individual project; we will reply as soon as we can.
