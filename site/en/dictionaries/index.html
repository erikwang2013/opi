2. Optional imported dictionaries (not bundled)

These dictionaries are downloaded, converted and imported by the user. The project repository does not contain them and does not download them at build time. Truncated 200k-entry files are available for direct import:

  • CustomPinyinDictionary 200k (about 2.9 MB)
  • rime-wanxiang 200k (about 4.9 MB)

3. Import limits per client

  • Android / macOS: at most 8 MiB / 200,000 entries per file. Android also limits active imports to 8 files and 500,000 entries in total. Use the 200k files above; full-size dictionaries are rejected.
  • Linux (fcitx5) / Windows (TSF): dictionaries are scanned directly from the dictionary directory, with no 8 MiB / 200k limit, so full-size files work.
  • iOS / HarmonyOS: no dictionary import entry yet.

Imported entries participate in candidate ranking: duplicate words take the larger of the main-dictionary frequency and the import boost, while unique words receive the boost. Large dictionaries can change candidate order; disable or delete them at any time in Settings.

4. Redistribution notes

  • When distributing installers, follow each bundled dictionary's license and include the corresponding source and license texts for GPL-3.0 / LGPL-3.0 data.
  • When distributing user-generated TSV files, keep the attribution and change notice header and link the upstream license.
  • Project-drawn pet and emoji assets are proprietary; see Visual asset license.
