隐私政策

小欧输入法（opi）· 六端一致

声明主体：小欧输入法（opi）项目

运营与联系人：艾瑞可 erik（个人开发者）

联系邮箱：erik@erik.xyz

生效日期：2026 年 10 月 28 日

适用范围：Android、iOS、鸿蒙、Windows、Linux、macOS 客户端及本网站（opi.erik.xyz）

一句话：小欧输入法不收集、不上传、不共享你的个人信息；没有账号体系，因此也没有「注销账号」这个动作。日常输入完全离线；只有你主动检查/下载更新或手动开启跨设备剪贴板时才联网，局域网剪贴板不经过云端。

1. 我们收集什么

我们不收集任何个人信息，包括但不限于：输入内容与候选词、剪贴板内容、通讯录、位置、照片、设备标识符、使用统计或崩溃日志。没有账号、注册或登录，也没有广告与用户画像。

2. 只保存在你设备上的数据

设置、皮肤、开关、用户词与学习记录只保存在你自己的设备上（各端的应用数据目录或配置目录），不会离开设备。由于没有账号，无需也无法申请注销账号；清除本地数据即完成删除：

  • Android / 鸿蒙：卸载应用或在系统设置中清除应用数据。
  • iOS：删除 App 即删除键盘扩展容器内的数据；不开启「允许完全访问」也能正常打字。
  • Windows / Linux / macOS：删除本机配置文件与用户词文件，或卸载应用。

3. 联网行为（均由你主动触发）

日常输入完全离线。只有以下情况会联网：

  • 版本检测：部分客户端的设置页提供「检查更新」，向 https://opi.erik.xyz/version.json 发起一次普通 HTTPS 请求，读取最新版本号。该请求不携带输入内容、用户词、剪贴板内容或设备标识，也不用于统计或画像。
  • 应用内更新：你点「下载」时，客户端访问安装包/热更新包并校验大小与 SHA-256；不携带输入或用户数据。
  • 跨设备剪贴板（可选，默认关闭）：只有你手动开启并完成配对后，才在同一局域网内与已配对设备建立加密连接（Noise + ChaCha20-Poly1305）；只同步纯文本（≤256 KiB），发现报文不含剪贴板内容，不经过云端、无账号、无历史；可一键停止并撤销设备。系统自带的云剪贴板可能独立同步，建议在系统设置中关闭。

4. 系统权限

  • Android：INTERNET（版本检测/更新/可选剪贴板/模型下载）、REQUEST_INSTALL_PACKAGES（把下载的安装包交系统安装器）、可选的局域网多播与前台服务/通知权限（跨设备剪贴板）。
  • iOS：可选「允许完全访问」用于把自有贴纸图片写入系统剪贴板；可选的本地网络权限用于跨设备剪贴板；键盘扩展不能使用麦克风，语音输入请使用系统听写。
  • 鸿蒙：网络权限（版本检测/更新/剪贴板）、可选的粘贴板权限（仅在启用剪贴板时）。
  • Windows / Linux / macOS：跨设备剪贴板首次监听时系统可能询问防火墙。

5. 第三方与共享

我们不出售、不出借、不共享个人信息，也不集成第三方广告、统计或追踪 SDK。本网站为静态页面，不设置分析型 Cookie，也不加载第三方统计脚本。

6. 儿童隐私

由于不收集任何信息，我们不会（也无法）收集儿童的个人信息。

7. 数据安全

输入与用户词不离开设备，因此不存在可供泄露的服务器端输入数据。版本检测只读取公开的版本号，使用 HTTPS 传输。

8. 你的权利

因为我们不持有你的个人信息，所以没有需要申请访问、更正、导出或删除的服务器端数据。本地数据始终由你控制：清除应用数据或卸载即可删除。如有疑问，欢迎通过邮件联系。

9. 政策变更

本政策可能随产品调整而更新，新版本会发布在本页并更新生效日期。由于没有账号体系，我们无法逐一通知；请以本页内容为准。

10. 联系我们

任何隐私问题或疑问，请发送邮件至 erik@erik.xyz。这是个人项目，我们会尽快回复。
